SPARQL Queries

Overview

This section documents all SPARQL queries used to explore Wikidata and DBpedia for Palmyra heritage data. These queries demonstrate the use of all required SPARQL keywords: OPTIONAL, DISTINCT, UNION, FILTER, REGEX, LIMIT, and ORDER BY.

Query 1: Extract All Monuments in Palmyra

Objective: Find all cultural properties in Palmyra with their descriptions

PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?item ?itemLabel ?description
WHERE {
  ?item wdt:P131 wd:Q5747 ;
        rdfs:label ?itemLabel ;
        schema:description ?description .
  FILTER (lang(?description) = "en")
}
ORDER BY ?itemLabel
LIMIT 20

Expected Results:

Returns monuments like Temple of Bel, Temple of Baalshamin, Arch of Triumph with descriptions.

Query 2: Find Monuments with Temporal Data

Objective: Extract construction and destruction dates using OPTIONAL

PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?monument ?monumentLabel ?constructionDate ?destructionDate
WHERE {
  ?monument wdt:P131 wd:Q5747 ;
           rdfs:label ?monumentLabel .
  OPTIONAL {
    ?monument wdt:P580 ?constructionDate .
  }
  OPTIONAL {
    ?monument wdt:P582 ?destructionDate .
  }
}
ORDER BY ?monumentLabel
LIMIT 50

SPARQL Features Used:

  • OPTIONAL — For properties that may not exist
  • DISTINCT — Avoid duplicate results
  • ORDER BY — Sort results

Query 3: Search Using REGEX Filter

Objective: Find temples and religious structures using pattern matching

PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?monument ?monumentLabel ?type
WHERE {
  ?monument wdt:P131 wd:Q5747 ;
           rdfs:label ?monumentLabel ;
           wdt:P31 ?type .
  FILTER (REGEX(?monumentLabel, "Temple|Arch|Theatre", "i"))
}
ORDER BY ?monumentLabel

SPARQL Features Used:

  • FILTER — Apply conditions
  • REGEX — Pattern matching (case-insensitive)
  • DISTINCT — Eliminate duplicates

Query 4: UNION Query — Destroyed and Restored Monuments

Objective: Combine multiple data patterns using UNION

PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?monument ?monumentLabel ?status
WHERE {
  {
    ?monument wdt:P131 wd:Q5747 ;
             rdfs:label ?monumentLabel ;
             wdt:P582 ?destructionDate .
    BIND("Destroyed" AS ?status)
    FILTER (YEAR(?destructionDate) >= 2015)
  }
  UNION
  {
    ?monument wdt:P131 wd:Q5747 ;
             rdfs:label ?monumentLabel ;
             wdt:P1435 wd:Q9259 .
    BIND("World Heritage" AS ?status)
  }
}
ORDER BY ?status ?monumentLabel

SPARQL Features Used:

  • UNION — Combine multiple patterns
  • BIND — Create new variables
  • FILTER — Filter by year

Query 5: Comprehensive Query with All Keywords

Objective: Demonstrate all required SPARQL keywords in one query

PREFIX wd: <http://www.wikidata.org/entity/>
PREFIX wdt: <http://www.wikidata.org/prop/direct/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?monument ?monumentLabel ?constructionDate ?destructionDate
WHERE {
  ?monument wdt:P131 wd:Q5747 ;
           rdfs:label ?monumentLabel .
  OPTIONAL {
    ?monument wdt:P580 ?constructionDate .
  }
  OPTIONAL {
    ?monument wdt:P582 ?destructionDate .
  }
  FILTER (
    REGEX(?monumentLabel, "Temple|Arch|Theatre|Museum", "i") &&
    (!BOUND(?destructionDate) || YEAR(?destructionDate) >= 2015)
  )
}
ORDER BY ?monumentLabel
LIMIT 30

All Required SPARQL Keywords:

  • DISTINCT — Eliminate duplicates
  • OPTIONAL — Handle optional properties
  • FILTER — Apply complex conditions
  • REGEX — Pattern matching
  • LIMIT — Restrict results to 30
  • ORDER BY — Sort alphabetically
